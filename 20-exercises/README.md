# Exercises (cross-course)

This folder contains **cross-course exercises** that are not tied to a single course folder.

Rule of thumb:
- If an exercise is clearly part of a specific course flow → put it inside that course folder.
- If it is transversal (same concept practiced across sources) → put it here.
- If it becomes a kata/mini-project with iterations → move it to **java-core-lab**.

## Workflow
- Branches: `exercises/<topic>`
- PR required (checkpoint)
- Squash merge only
