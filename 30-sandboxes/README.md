
# Sandboxes

This folder is for **quick spikes** and throwaway experiments that are **not** worth moving to the Labs repo yet.

Rule of thumb:
- **Sandbox** = fast exploration, minimal structure, short-lived
- **Exercises** (`20-exercises/`) = transversal practice you want to keep
- **Labs repo** = katas, mini-projects, iterations, longer practice tracks

## Workflow
- Branches: `sandbox/<topic>`
- PR required (checkpoint)
- Squash merge only

## Naming
Prefer short, intent-based names:
- `sandbox/spike-enums`
- `sandbox/spike-io`
- `sandbox/spike-streams`

## Cleanup policy
If a sandbox becomes valuable:
- move it to a course folder (if it belongs to a course), **or**
- move it to `20-exercises/` (if transversal), **or**
- move it to the Labs repo (if it becomes iterative practice)
